AI Showcase images for the home page hero
=========================================

Four tiles, 2 x 2, shown only on desktop screens (1100px wide and up).

Files (put them in this folder):
  ai-1.jpg   top left
  ai-2.jpg   top right
  ai-3.jpg   bottom left
  ai-4.jpg   bottom right

Size: about 800 x 600 pixels (4:3), JPG or WebP-renamed-to-.jpg is fine. Keep each under about 150 KB.
The picture is cropped to fill the tile (object-fit: cover), so keep the furniture near the middle.

Use real AI designs made with the site's Customize page. Do not use stock photos of finished work.

To change the file names or the alt text, edit config/hero.php (key "ai_images").
Until a file exists, its tile shows a neutral drawing with an "AI sample" badge.
Every tile and the "Design yours" link open the Customize page.
