What changed

  • Icons: Assistant, My Orders, Cart and Notifications icons are now the same height as the words. Use the Navbar icons switch to compare with how they look today.
  • My Orders: a new navbar item with an icon. The Order History button on the Notifications page is gone.
  • Which notifications get a View details button: order notifications and service notifications (custom design, refunds and invoices). Account notices like Identity Verified, Password Updated and Contact Details Updated only get Mark read, because there is nothing more to open.
  • Filters: Mark all as read, Only show unread and Dates (from, to) sit in one row on desktop and on the phone.
  • Buttons: no left or right arrows on any button, only words (View details, not View details with an arrow).
  • Luma: hides while the notification panel is open and comes back with the same conversation.
